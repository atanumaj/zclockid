Active Directory Domain & Forest Functional Levels

Unlock advanced Kerberos claims, Privileged Access Management (PAM), AES-256 encryption, and modern AD directory features

Domain Level (DFL) 2016
Windows Server 2016

Governs Kerberos armoring, dynamic access control, and domain security policy.

Forest Level (FFL) 2016
Windows Server 2016

Governs cross-forest trust mechanisms, global catalog replication, and schema attributes.

Lowest DC Level 2008_R2
Windows Server 2008 R2

Active Directory DC operating system version capability across all replication peers.

Why is the baseline functional level Windows Server 2008 R2?

Pure Samba 4 Active Directory domain controllers run at the Windows Server 2008 R2 functional level for DRS replication stability and cross-vendor compatibility. Windows 10/11 clients, modern RSAT tools, AES-256 Kerberos, and Server 2016/2019 schema extensions remain fully supported on this baseline. Raising the functional level to native 2016 requires Windows Server 2016+ DCs holding the Schema Master role.
