Appliance Role Hierarchy & Capability Matrix

fulladmin

Complete, unrestricted read and write control over all domains, RADIUS, DNS, certificates, and system updates.

operator

Can manage users, groups, RADIUS clients, MAB MAC addresses, and registrations. Cannot modify certs or system settings.

report

Read-only auditing access to compliance logs, RADIUS telemetry, Sysvol sync health, and active live log viewers.

readonly

Safe inspection mode. All configuration modification buttons, provisioning actions, and toggles are locked.
