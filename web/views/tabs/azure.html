Microsoft Entra Setup Guide

Required setup in your Microsoft 365 / Entra tenant

  1. 1
    Register Application in Azure Portal

    Go to entra.microsoft.com → Applications → App registrations → New registration (name it e.g. ZclockID-CloudSync).

  2. 2
    Grant Graph API Permissions

    Navigate to API permissions → Add a permission → Microsoft Graph → Application permissions, then check:

    User.ReadWrite.All Directory.ReadWrite.All Group.ReadWrite.All

    Click "Grant admin consent for tenant".

  3. 3
    Generate Client Secret

    Under Certificates & secrets → New client secret. Copy the secret Value (not Secret ID) immediately.

  4. 4
    Paste & Test Connection

    Fill in the fields on the left and click Test Connection to verify token acquisition.

Why Native Linux Sync?

Traditional setups require running a dedicated Windows Server VM solely to host Microsoft Azure AD Connect / Cloud Sync agent, costing thousands in Windows Server CALs.

ZclockID uses an asynchronous daemon (zclock-azuresync) communicating directly with Microsoft Graph REST endpoints over outbound TLS 443, eliminating external Windows dependencies entirely.
