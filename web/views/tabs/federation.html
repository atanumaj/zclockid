Hub & Satellite Identity Architecture

Understanding how ZclockID and Keycloak interact in an enterprise environment.

ZclockID (Identity Core)
  • Authoritative Active Directory Domain Controller
  • Kerberos KDC for Windows / Linux domain joining
  • LDAP / LDAPS Directory Service (Port 389 & 636)
  • FreeRADIUS 802.1X Wi-Fi & Switch Port Security
  • Native Samba Sysvol & Group Policy Objects (GPO)
Keycloak (SSO Gateway)
  • Web Single Sign-On (OIDC / OAuth2 / SAML 2.0)
  • Federates user credentials directly from ZclockID LDAP
  • Protects web apps (Nextcloud, Grafana, Portals, M365)
  • Enforces Multi-Factor Authentication (TOTP / WebAuthn)
  • Zero JVM impact on core Active Directory appliance

4-Step Deployment Walkthrough

1
Deploy Keycloak: Use the Docker Compose Blueprint tab to launch Keycloak on your application host (e.g. 192.168.1.38).
2
Configure LDAP Provider: In Keycloak, add an LDAP provider using the copy-paste values from the LDAP Federation Preset tab.
3
Sync Users: Click "Sync All Users" in Keycloak. Your ZclockID Active Directory users and groups are now live in Keycloak!
4
Enable SPNEGO (Optional): Export the Kerberos keytab from the Kerberos SPNEGO tab for silent browser single sign-on.
