Microsoft RSAT Administration & Snap-in Guide 100% MMC Compatible

Manage ZclockID Samba AD DC natively from your Windows workstation using official Microsoft MMC consoles

Docs
1 Install RSAT on Windows 10 / 11

RSAT is included with modern Windows as an Optional Feature. Open PowerShell as Administrator and run:

Get-WindowsCapability -Name RSAT* -Online | Add-WindowsCapability -Online
GUI: Settings → Optional features → RSAT
2 Point DNS & Join Domain
Set Preferred DNS: Point client IPv4 DNS to ZclockID (appliance-ip).
Join Domain: In sysdm.cpl, join domain DOMAIN.
Log In: Sign in with Domain Administrator credentials (Administrator@example.com).
Both Domain Admin and delegated accounts supported
3 Launch MMC Snap-in Consoles

Press Win + R and run any snap-in:

Group Policy (GPMC)
DNS Manager Console
