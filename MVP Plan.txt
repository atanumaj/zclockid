2. Sysvol Strategy (Option A - Upstream Safe)
Physical Location:
Preserved at default /var/lib/samba/sysvol/ for 100% Ubuntu/Debian package upgrade safety.
Symlink Access:
/zclockid/data/sysvol -> points directly to /var/lib/samba/sysvol.
Sysadmins can navigate directly from /zclockid/ to inspect GPOs, scripts, and policies.
Permission Integrity (NTACL):
Backups preserve Windows NT Security Descriptors via extended attributes: tar --xattrs --xattrs-include='*' -czf backup.tar.gz /zclockid /var/lib/samba/sysvol
zclock-sysvold daemon watches /var/lib/samba/sysvol and automatically executes samba-tool ntacl sysvolreset whenever replication finishes.
3. Engine Integration (How /etc Points to /zclockid)

Operating system services stay standard, but their configuration files point to /zclockid/:

Samba: /etc/samba/smb.conf contains: include = /zclockid/config/samba/smb.conf

FreeRADIUS: /etc/freeradius/3.0/clients.conf contains: $INCLUDE /zclockid/config/freeradius/clients.conf

BIND9: /etc/bind/named.conf.local contains: include "/zclockid/config/bind/named.conf.zclockid";

Nginx: /etc/nginx/sites-enabled/default contains: include /zclockid/config/nginx/zclockid.conf;

Systemd Services: Units live in /etc/systemd/system/zclock-*.service and point directly to execution paths in /zclockid/api/ and /zclockid/daemons/.

4. Terminal Administration & Sysadmin Freedom
Zero Shadow State:
Samba sam.ldb is the sole source of truth for AD users/groups.
Native tools ('samba-tool user add', 'rndc', 'systemctl') work directly.
Safe Overrides:
Sysadmins can add custom rules into /zclockid/config/overrides.d/.
The Web GUI will never overwrite sysadmin terminal overrides.
Atomic Validation:
Any config generated by the GUI is pre-validated with native tools ('testparm', 'named-checkconf', 'freeradius -C') before reloading services.
5. Disaster Recovery & Migration
Comprehensive Backup Command:
tar --xattrs --xattrs-include='*' -czf zclockid-backup-$(date +%F).tar.gz /zclockid /var/lib/samba/sysvol
Clean Restore:
Extract the backup archive on a fresh machine.
Re-link systemd units and restart services. Appliance is 100% operational.

MVP3: 

1. Role-Based Access Control (RBAC) & GUI Access
Architecture & UI Placement:
Located under: System -> Access Control & RBAC (Dedicated Sub-Tab).
Hybrid Directory Mapping (AD + Local Break-Glass):
Primary: Active Directory users and groups map directly to appliance roles.
Break-Glass: A built-in local admin account is maintained in /zclockid/db/ to guarantee emergency console/GUI access if Samba or LDAP is temporarily down.
Role Definitions & Permissions:
fulladmin (Full Administrator):
Unrestricted read/write across all subsystems.
Can manage FSMO roles, system identity, API keys, TLS certs, and backups.
operator (User & Group Manager):
Can create, edit, unlock, and delete AD Users and Groups.
Can approve/reject Guest Self-Registrations and assign Bandwidth Profiles.
Blocked from system-level settings, network configuration, and certificates.
report (Auditor & Analytics):
Access to Telemetry, Sysvol sync health, active RADIUS sessions, and Syslog viewers.
Cannot make any modifications or view sensitive user secrets.
readonly (Read-Only Inspector):
Complete view of the entire appliance for inspection and troubleshooting.
All mutation actions (Save, Delete, Restart, Provision) are disabled/hidden.
Role Mapping Configuration (In UI):
Table of Mappings:
Domain Admins (AD Group) -> fulladmin
Helpdesk-Tier2 (AD Group) -> operator
Compliance-Team (AD Group) -> report
Custom User johndoe -> operator (Direct user override)
2. API Key Management
Located Under: System -> API Keys
Key Generation:
Generate cryptographically secure API tokens (e.g., zck_live_8f93a1...).
One-time secret display with 1-click copy.
Granular Scopes:
admin:all -> Complete system control (CI/CD and deployment pipelines).
users:manage -> Provision and update AD accounts (HR software integration).
radius:read -> Query live sessions and accounting (Billing & portal integration).
telemetry:read -> Read-only metrics (MSP Fleet Manager / PRTG / Prometheus).
Security Restrictions:
CIDR Whitelisting: Restrict key usage to specific management IPs (e.g., 10.10.0.50/32).
Expiration Dates: Set key validity (30 days, 90 days, 1 year, or Never).
Immediate Revocation: 1-click revoke button to instantly kill compromised keys.
3. GUI Certificate Management & TLS Controls
Located Under: System -> Certificates

Certificate Operations:

Generate Self-Signed Certificate:
1-click generation with custom Subject Alternative Names (SANs).
Automatically includes Appliance IP, FQDN (dc1.inet.net), and NetBIOS name.
Upload Custom Enterprise Certificate:
Form to upload Certificate (.crt / .pem), Private Key (.key), and Intermediate CA bundle.
Supports corporate PKI (Microsoft AD CS, DigiCert) and wildcard certs.
Generate Certificate Signing Request (CSR):
Generate CSR directly from the appliance to submit to an enterprise CA.
Let's Encrypt / ACME (Optional):
Automatic HTTP-01 / DNS-01 issuance and 90-day renewal.

Web Engine & TLS Version Controls:

HTTP -> HTTPS Automatic Redirect toggle.
Enforce TLS Protocol Version: Select TLS 1.3 Only or TLS 1.2 + TLS 1.3.
HSTS (HTTP Strict Transport Security) toggle with max-age header.
Automatic validation: Tests certificate and Nginx configuration before reloading.
4. Centralized Enterprise Syslog Subsystem
Located Under: System -> Syslog & Logging

Syslog Forwarder Settings:

Remote Syslog Server: Hostname / IP address (e.g., 192.168.1.50).
Port & Protocol: UDP (514), TCP (514), or Encrypted TLS (6514 with CA verification).
Log Format Standard:
RFC 5424 (Modern structured Syslog with timestamp and hostname).
RFC 3164 (Legacy BSD Syslog for older SIEM collectors).
JSON (Structured JSON stream for Splunk, Wazuh, ELK, or Graylog).

Granular Log Source Toggles (Select what to send):

 Samba AD DC Logs: Kerberos authentications, NTLM auth, failed logon attempts, LDAP queries, DRS sync.
 FreeRADIUS Logs: 802.1X Access-Accept, Access-Reject, Dynamic VLAN assignments, and accounting starts/stops.
 System & Kernel Logs: Operating system events, hardware health, disk telemetry, network interface link events.
 Auth & Security Logs: /var/log/auth.log, SSH logins, sudo commands, and console access.
 ZclockID Management Audit Trail: Tracks every Web GUI and API action: Who made the change, timestamp, source IP, and payload.
